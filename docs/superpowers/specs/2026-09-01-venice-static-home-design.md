# Venice 风格静态首页设计

## 目标

将根路由从空页面改为 Venice 风格的静态 AI 首页视觉稿，同时保留现有 `/chat` 及其他聊天子路由不变。首版只验证页面构图和视觉方向，不接真实模型或聊天接口。

## 页面范围

首页包含全屏波纹背景视频、品牌导航、居中的 Ask anything 组合输入框、快捷 prompt 胶囊按钮、模型提供商横向展示、能力区静态卡片、定价区静态卡片、开发者 API 代码面板、隐私架构区和页脚。

输入框和按钮只承担视觉展示职责。导航链接可以指向现有页面，Sign up 指向注册页；聊天提交、价格切换、能力切换、菜单展开和代码示例切换均不在本版实现。

## 技术方案

继续使用项目现有的 Next.js App Router、React、Tailwind CSS、Motion 和 Lucide React。页面组件放在 `components/marketing/`，根路由页面放在 `app/(marketing)/page.tsx`。背景视频、图片和字体先使用远程 CDN 资源，后续确定品牌方向后再替换为自有素材。

静态能力区在桌面端使用左右两列网格，在移动端堆叠。首屏使用 `min-height: 100svh`，背景视频使用 `object-fit: cover`，底部增加米白渐变遮罩。颜色沿用 Venice 观察到的海蓝、石膏米白、浅棕和蓝色强调色，但通过页面局部样式隔离，避免影响聊天界面。

## 验收标准

根路由不再为空，桌面端首屏具备 Venice 风格的全屏视频背景和居中输入组合。移动端宽度 375px 时导航和输入组合不发生横向溢出，快捷按钮可以横向滚动。页面其余区块能够正常纵向浏览，没有遮挡和布局塌陷。现有聊天相关测试和路由行为不被改动。
